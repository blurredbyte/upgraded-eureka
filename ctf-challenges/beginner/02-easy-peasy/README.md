# Easy Peasy Lemon Squeezy

**Category:** Web
**Difficulty:** Beginner
**Points:** 50

## Description

We have a new website, but our developers are still learning about security. They've been told to hide some files from web crawlers, but they might have misunderstood what "hiding" means.

Can you find the hidden flag?

**Challenge Link:** [http://challenge.example.com/](http://challenge.example.com/)

*(Note: For the purpose of this CTF, the necessary files are provided in the `files` directory. You will need to examine them to find the flag.)*

## Hints

*   How do websites tell search engines what not to index?
*   Look for a file that is meant for robots.
