# The Decoder

**Category:** Crypto
**Difficulty:** Beginner
**Points:** 75

## Description

We've intercepted a secret message, but it seems to be encoded. Our top cryptographers are on vacation, so we need your help to decode it.

The message is in the `message.txt` file. Can you decode it and find the flag?

## Hints

*   This is a very common encoding scheme used to represent binary data in an ASCII string format.
*   The character set includes A-Z, a-z, 0-9, +, and /. It might also have a `=` at the end.
*   There are many online tools that can decode this for you. Just search for "base64 decoder".
