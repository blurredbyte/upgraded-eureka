# When in Rome

**Category:** Crypto
**Difficulty:** Beginner
**Points:** 75

## Description

One of our historians found an ancient scroll with a message on it. It seems to be written in some kind of code. The message is in the `encrypted-message.txt` file.

Can you help us decipher it?

## Hints

*   The title of the challenge is a big clue. "When in Rome..."
*   This is one of the oldest and simplest forms of cryptography.
*   The key is a number, and you just need to shift the letters of the alphabet by that amount. Maybe try all possible keys? There are only 25 to check for the English alphabet.
*   The key is 13. Or is it? You should try to figure it out yourself. The key is how many letters you shift. For example, with a key of 1, 'A' becomes 'B'.
*   The flag format is `ICIMS{...}`. The curly braces and the `ICIMS` part are not encrypted.
