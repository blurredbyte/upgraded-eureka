# Secrets in the Code

**Category:** Secrets Hardcoded
**Difficulty:** Beginner
**Points:** 100

## Description

A developer was working on a new feature and accidentally committed a secret to the codebase. They realized their mistake and quickly removed it in a later commit.

We've recovered the files from the two commits. Can you find the secret that was removed?

The files are in the `files` directory.

## Hints

*   Look for files that might contain sensitive information, like configuration files.
*   Compare the different versions of the files. What was changed?
*   Sometimes secrets are not in the latest version of the code, but in its history.
