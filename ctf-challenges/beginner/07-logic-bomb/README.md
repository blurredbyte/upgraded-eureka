# Logic Bomb

**Category:** Developer-Friendly
**Difficulty:** Beginner
**Points:** 100

## Description

One of our developers created a login script, but it seems to have a flaw. Can you find a way to log in without knowing the password?

The script is in the `files` directory. You can run it with `python login.py`.

## Hints

*   You don't need to guess the password.
*   Read the Python code carefully. How does it check the password?
*   What happens if you enter a negative number? The script is expecting a number, but what kind?
